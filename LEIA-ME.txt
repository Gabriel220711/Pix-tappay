# TapPay — versão para várias lojas

Este pacote adapta o site TapPay para atender várias placas NFC com um único site.
Cada placa guarda um link com um identificador, por exemplo:
- https://gabriel220711.github.io/Pix-tappay/?id=barbearia01
- https://gabriel220711.github.io/Pix-tappay/?id=loja02

O identificador `id` encontra a loja no banco de dados. Cada registro pode ter uma chave Pix diferente.

## 1. Criar o banco gratuito no Supabase
1. Crie uma conta/projeto em https://supabase.com/
2. Abra **SQL Editor > New query**.
3. Cole todo o conteúdo de `supabase.sql` e clique em **Run**.
4. Abra **Project Settings > API** e copie:
   - Project URL
   - anon / public key

## 2. Conectar o site
1. Abra `index.html`.
2. Procure `COLE_A_URL_DO_SEU_PROJETO` e substitua pela Project URL.
3. Procure `COLE_A_CHAVE_ANON_PUBLIC` e substitua pela chave anon/public.
4. Salve o arquivo.

A chave `anon/public` é feita para estar no navegador. Nunca coloque `service_role`, senha do banco ou chave secreta no HTML.

## 3. Publicar no GitHub Pages
1. Abra o repositório `Pix-tappay` no GitHub.
2. Substitua o `index.html` pelo deste pacote.
3. Faça Commit changes.
4. Mantenha GitHub Pages configurado para `main` e `/ (root)`.

O endereço base continua:
https://gabriel220711.github.io/Pix-tappay/

## 4. Cadastrar uma loja
No Supabase:
1. Abra **Table Editor > lojas > Insert row**.
2. Preencha pelo menos:
   - `slug`: identificador único, sem espaços (ex.: `barbearia01`)
   - `nome`: nome que aparecerá no site
   - `chave_pix`: chave Pix do estabelecimento
   - `nome_recebedor`: nome do titular/recebedor usado no QR
   - `cidade`: cidade do recebedor (ex.: `SAO PAULO`)
3. Opcionalmente preencha `whatsapp` (com DDD e número), `instagram`, `linkedin`, `wifi_nome` e `wifi_senha`.
4. Deixe `ativa` como `true`.

A página da loja será:
https://gabriel220711.github.io/Pix-tappay/?id=barbearia01

## 5. Gravar na placa NFC
Grave somente a URL exclusiva daquela loja usando NFC Tools:
`https://gabriel220711.github.io/Pix-tappay/?id=barbearia01`

Para outra loja, cadastre outro `slug` e grave outro link na placa.

## Atenção sobre o Pix
- Cada identificador consulta um cadastro diferente; portanto, cada loja mostra sua própria chave Pix.
- A chave Pix e os dados de contato ficam visíveis para quem abrir a página. Isso é esperado para uma página de pagamento.
- O QR é um Pix estático montado com a chave e os dados do recebedor. Teste com o aplicativo do banco antes de entregar a placa e confirme nome/CPF-CNPJ do recebedor antes de pagar.
- Não há confirmação automática de pagamento nem integração com extrato. O lojista deve conferir o recebimento no próprio banco.
- O valor é opcional. Se preenchido, ele é incluído no QR.
- O cadastro é feito pelo painel do Supabase, não por um painel administrativo público no site. Isso evita deixar uma tela de cadastro aberta para qualquer pessoa.
- Não cadastre dados que a loja não autorizou divulgar. Em especial, só mostre a senha do Wi-Fi se o estabelecimento quiser compartilhá-la publicamente.
